# Fascinating Bot

Funciones:
- Se une automáticamente a `🎵・Music` cuando un usuario entra.
- Revisa NightLight cada 15 minutos y publica nuevos códigos DBD en `🎁・dbd-codes`.

Importante:
- El bot no puede ordenar a Jockie que se una; Discord no permite controlar otro bot de esa manera.
- Nunca pongas el token de Discord dentro del código. En Render se configura como variable de entorno `DISCORD_TOKEN`.
